03

IP 矩阵代际换班（"三阶不确定性"）

事件

招股书时代 7 个 Top IP 5 年后命运分化：S 曲线突破率 14% / 边缘化率 14% / 退场率 43%。完整的 IP 三阶模型：

  • 一阶：哪个新 IP 突破 — LABUBU（131x）、CRYBABY、HIRONO
  • 二阶：哪个 Top IP 边缘化 — PUCKY 从 22.8% 占品牌产品到 Top IP 列表消失
  • 三阶（2026 新增）：边缘化 IP 被重启 — PUCKY 通过"敲敲系列 + 运营重启"复活，王宁亲口披露
对当前 38.1% LABUBU 集中度的隐含意义：即使 5 年后下滑到 10%，也可能再被运营重启——是对 Bernstein 看空命题的深层反驳。

长周期对照镜鉴

对照

没有任何 IP 龙头跳过 5–10 年的下滑+改革重启周期。Pop Mart 上市仅 5 年（2020-12 至今）从未经历过完整周期下滑，这是当前 14x PE 估值最大的隐含不确定性。

公司下滑期触发对 Pop Mart 的镜鉴
乐高1994–2004（10 年）专利到期 + 盲目扩张 + 电游冲击中国玩具份额第一（9.0%）—— 国内最大对手
三丽鸥1992–2010（16 年）+ 2015–2020（6 年）Hello Kitty 单 IP 老化减集中度路径：54.2% → 30.4%
万代南梦宫2006–2010（合并初期 5 年）整合阵痛IP 轴战略 + Group Shared ID 数据中台
三丽鸥（近期）FY2024 北美 +121% → FY2025 H1 +12.0%美国关税骤降 109pp —— Pop Mart 美洲 +748% 早期警告

10

外部生态视角

对照

千岛 APP（2019 创办，与 LABUBU 起跳同代际）—— 中国最大潮玩 IP 二手交易平台，2025 成交额预计 >100 亿。沈振宇访谈给出 wiki 内第一份独立外部从业者视角的硬数据点：

  • 价格反身性机制："越降价越没人要，越涨价大家买得越凶"——双向反馈机制
  • 黄牛 <5% 人数 / <20% 交易量——证伪"黄牛炒作主导"叙事
  • 专业玩家整体亏损至少 30%——Labubu 是"极少的例外"
  • "下一个 Labubu 很快会来"命题——对 Bernstein 看空命题的第一个独立外部反向论据
  • 月产 2000–3000 万只搪胶毛绒已锁定产能上限（首次外部口径）

另有纽约 Oculus 实地访店（2026-05-06）给出零售一手观察 + 方法论自觉：双锚估值框架（自有 IP 公司 15-25x vs 渠道商 15-20x）+ Q2 财报 3 条减仓红线。
