TL;DR

外界对泡泡玛特估值的最大焦点常被表述为 "LABUBU 销售能否持续？"——但这个提法看上去重要、实际错位。

王宁本人公开"不担心 LABUBU 持续"（关心的是组织）；沈振宇说"现象级 IP 不会归零"；Bernstein 说"Beanie Babies 类比"。三方打的不是同一场仗——王宁/沈振宇回答存在性问题，Bernstein 担心清醒销售基线问题。

真正驱动估值波动的是另外三件事：LABUBU 减速斜率 / 第二梯队能否破 50 亿门槛 / 组织能力能否撑起全球化+集团化双战略。

① 核心问题重构：真问题 vs 伪问题

同样是问"LABUBU 是否持续"，不同提法的可证伪性差很多。先把伪问题剥离出去，让分析精力聚焦在能动的变量上。

提法性质判断依据
LABUBU 会不会归零 伪问题 1–1.5 亿只实物在用户家中（王宁 2026 初口径）—— 存在性已确定；沈振宇 "真粉丝托底" + 王宁 "实物 IP 持续加深认知" 双重论据。
LABUBU 会不会回吐 真问题但是节奏 2026 已主动暂停新品 + 暂停线下营销 + 暂停大量合作 —— 是 "减速到什么斜率" 问题，不是命运问题。
第二梯队能否接力 50 亿 最该关注 SKULLPANDA 35.4 亿 / CRYBABY 29.3 亿 / Twinkle Twinkle 20.6 亿 —— 距林奇阈值仍差 15–30 亿。任一突破 = 估值倍数重估上行；都不破 = LABUBU 单点依赖加剧。
组织能力能否撑住 最该关注 王宁 2025 自评 70 分（vs 2024 80 分）；海外门店运营 "还是 2-3 年前国内水平"；1 万人组织 "千里之堤溃于蚁穴"。
提醒：王宁的 "不担心 LABUBU" 和 Bernstein 的 "Beanie Babies 类比" 并非真正交锋。 王宁回答 "实物 IP 会不会消失"（存在性），Bernstein 担心 "投机泡沫破后真粉丝清醒销售基线在哪里"（节奏）。 两者打在不同的维度上 —— 把 "王宁不担心" 直接拿来反驳 Bernstein 是逻辑错位。

② 4 层硬度递减评估框架

按 "可量化程度 + 可证伪程度" 从高到低排列。硬度越高的层，越不可争议（财务底座是估值下限锚）；越软的层，越是估值倍数的来源（品牌叙事决定 PE 倍数从 10x 到 40x 的跨度）。

A 层财务底座 最硬 · 估值下限锚

来源：2025 年报 + Q1 2026 自愿性公告
  • 营收 371.20 亿 / 调整后净利 130.84 亿 / 净利率 35.2%（已接近 LVMH 区间）
  • 零银行借款 + 净现金 137.75 亿 + 海外占比 43.8%
  • Q1 2026 整体 YoY +75–80%（中国 +100% 仍是最快增速区）
  • 派息率 24.4%（略高于 20% 下限，CapEx 翻倍至 11.72 亿）
✓ 这一层不可争议。除非 2026 中报出现 "基本面拐点"（Bernstein 持续追踪 20+ 项高频数据未见），否则财务底座是估值下限锚。
🤔 但 35% 净利率是高位。进一步杠杆来自 "绝对值放大 + 净利率维持"，而非 "利润率扩张"。

B 层IP 资产质量 次硬 · 增长持续性

来源：5 年 IP 序列 + 王宁 2026 初聚焦战略 + 沈振宇命题
  • ⚠️ LABUBU 单 IP 占 38.1% — 比 2019 年 MOLLY 单极时代（27.1%）更集中
  • ✓ 但 17 个艺术家 IP 破亿，矩阵厚度仍在
  • ⭐ 王宁主动战略：资源聚焦 4 头部（LABUBU / 星星人 / MOLLY / SKULLPANDA），"比再签 10 个新 IP 更有价值"
  • ⭐ "下一个 LABUBU" 实证：PUCKY 通过运营复活（敲敲系列） + 星星人 2025 营收 20.6 亿（+225%）
🤔 关键不确定：第二梯队 IP（SKULLPANDA / CRYBABY / Twinkle / HIRONO）能否在 2026–2027 突破 50 亿元年营收。当前最高 SKULLPANDA 35.4 亿，距阈值差 14.6 亿。

C 层渠道 + 组织能力 更软 · 下行风险源

来源：王宁 2026 初访谈自评 + 海外门店运营落差描述
  • 渠道：全球全直营（不加盟） + 1,824 台机器人商店 + 抽盒机/抖音/天猫/小程序多线上
  • Say No 公司哲学："我们 say no 次数远大于 say yes"（主动放弃合作/授权/加盟）
  • ⚠️ 王宁自评 组织 70 分（2024 是 80 分）— wiki 内首次量化的 "组织退步" 披露
  • ⚠️ "海外门店运营还是 2-3 年前国内水平" — 工程质量 / 陈列 / 商品管理 / 服务运营全面落差
⚠️ 组织退步是隐形信号。业绩好的时候掩盖问题，"千里之堤溃于蚁穴" — 是王宁本人最担心的维度，比业务问题更值得跟踪。

D 层品牌叙事位势 最软 · 决定 PE 倍数

来源：林奇 Lens + Bernstein 看空 + 沈振宇看多 + LVMH 借鉴
  • LABUBU 已不只是商品 — 身份表演媒介（短视频时代 "表达 → 表演" 传播学）+ "现象级实物 IP"
  • 看多叙事："中国迪士尼" / "未来 50 年 Hello Kitty" / 实物 IP 持续加深认知
  • 看空叙事："漂亮 50" / Beanie Babies 类比 / S 曲线进入第二阶段平台期
  • ⭐ 治理升级：吴越（LVMH 中国区总裁）2026 加入董事会 — 引入 "看家 60% + 创新 40%" 框架（Nike 鞋款 / 香奈儿包款）
当前 PE 14.6x 处于 "贵估值修正完毕、便宜叙事尚未建立" 中间态。
估值倍数区间：中国迪士尼叙事 → 30–40x / 平台期叙事 → 15–20x / Beanie Babies 类比 → 10x 以下都贵。

③ 看多 vs 看空 — 5 维并列论据

本框架不强行选边。任何 "中国迪士尼" 或 "Beanie Babies" 叙事都是信念而非结论 — 并列保留，让读者按自身风险偏好取舍。

看多论据

  • 实物 IP 不归零：1 亿只 LABUBU 在用户家持续存在；真粉丝托底
  • 运营能力实证：PUCKY 复活 + Twinkle Twinkle 起跳
  • 集团化战略：全球化 + 集团化双轮（IPO 时即提）
  • 海外 43.8%：文德一 4 年埋种期回报；2024 美洲 +748%
  • PE 14x 区间底：历史 15-25 分位；2024-01 "17.5x 被低估" 后被打穿 2.6x

看空论据

  • 存在 ≠ 复购：二手价崩塌（待跟踪千岛 GMV）
  • 规模不够：第二梯队都是次级 IP，50 亿门槛未破
  • 电影/游戏自评：王宁口径 "不够成功"；甜品/家电试错成本未量化
  • 海外运营落差：王宁自述落后国内 2-3 年；关税敞口
  • PE 还可压缩：2025-08 峰值后；Bernstein "10x 以下都贵"

④ 关于 "耐克 60/40" 类比

王宁 2026 初访谈第 11 节，吴越提出（王宁附和）：

"每个品牌都得有自己看家的东西，可能每年有 60% 的东西是看家的，不需要做太大的创新，但需要把这个看家的东西不断完善，然后有 40% 要做持续的创新。比如 Nike 的鞋子，香奈儿那几款包……"

这是 Pop Mart 治理层级出现的 奢侈品逻辑 — "看家 IP（LABUBU / MOLLY / SKULLPANDA）持续维护 + 新品类与新 IP 创新 40%" 取代了 "广撒网造星"。

类比的合理性

  • Nike 经典款（Air Force 1 / Jordan）持续 30–40 年
  • Hermès Birkin/Kelly 持续 50+ 年
  • 实物 IP 在用户家持续存在（与王宁 "1 亿只不消失" 同源）
  • 减少创新失败的财务波动（"linear corporate growth" 目标）

类比的反驳

  • Nike / Hermès / 香奈儿都有百年品牌势能；LABUBU 真正出圈仅 18 个月
  • 潮玩用户审美迭代速度快于运动鞋/奢侈品
  • "看家" 地位是事后才能确认 — Beanie Babies 当年也曾被视为 "看家"

⑤ 估值锚定（框架而非结论）

本框架 不给目标价 — 卖方目标价 130~330 跨度 2.5x 已经反映了 D 层叙事的分歧。但可以按层级给出 "锚" 与 "倍数来源"：

层级锚估值含义
A 财务底座调整后净利 130.84 亿 × 15x PE = HK$2,300 亿（≈ HK$172/股）估值下限
B IP 资产海外占比 + 第二梯队进度决定增长持续性
C 渠道+组织王宁 70 分自评下行风险源
D 品牌叙事吴越加入 / 灭火动作 / Bernstein 维持 Sell决定 PE 倍数（10–40x 跨度）
评估纪律 4 条：
  1. 优先关注 A 层和 B 层（硬指标 / 可量化）
  2. C 层是下行风险的早期信号 — 王宁自评退步是 wiki 内首次明确的 "组织风险" 披露
  3. D 层是估值倍数的来源但不可争论 — 任何 "中国迪士尼/Beanie Babies" 叙事都是信念而非结论
  4. 创始人视角 ≠ 投资者视角 — 王宁始终在做 "让市场理解公司" 工作，把他的判断当论点而非结论

⑥ 验证窗口

短期（2026 H1 中报）

  • LABUBU 同比增速：+30%? +50%? +0%? — 主动控热的财务代价首次量化
  • 海外门店运营标准化 — 是否有海外区域总部 + HR 体系升级披露
  • 第二梯队 IP — SKULLPANDA / CRYBABY / Twinkle Twinkle 是否任一突破 25 亿单 IP 半年

中期（2026 年报）

  • 4 个头部 IP（LABUBU / 星星人 / Molly / SKULLPANDA）的资源聚焦结果
  • 砍掉的 1–2 亿业务披露
  • 第二梯队 IP 突破 50 亿门槛与否

长期（2027–2030）

  • 能否复制 Hello Kitty 减集中度路径（4 年 54.2% → 30.4%）
  • 海外占比是否突破 60%
  • 集团化（电影 / 游戏 / 乐园 / 甜品 / 家电 / 饰品）是否有任一业务单独贡献营收 >10 亿
